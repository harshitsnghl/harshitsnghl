# Hi, I'm Harshit 👋

**Software Engineer @ Bajaj Finserv Health** — I build and maintain the backend systems behind health insurance products and partner integrations.

Mostly Java and Spring Boot, a lot of MongoDB, and a healthy amount of Kafka. I enjoy problems that involve moving large volumes of data reliably between systems that were never designed to talk to each other.

---

### 🔧 What I work on

- **Backend services** in Java / Spring Boot — REST APIs, third-party integrations, and internal platform tooling
- **Event-driven pipelines** with Kafka — consumers, DLQ handling, circuit breakers, and retry semantics that hold up under load
- **Data layer** — MongoDB aggregation pipelines, bulk write patterns, and indexing strategy for reporting workloads
- **Concurrency & throughput** — virtual threads, batching, and tuning high-volume ingestion

### 🧪 What I tinker with

- Running **local LLMs** (LM Studio, Gemma, DeepSeek) and wiring them into my day-to-day dev workflow
- **AI developer tooling** — custom agent skills, model routers, and gateway proxies
- A slightly obsessive **Obsidian vault** for engineering notes, system design writeups, and everything I'd otherwise forget
- **DSA & problem solving** — the fundamentals keep paying rent
